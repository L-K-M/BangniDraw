# MULTIPLY — dst src opacity expected, premultiplied ARGB8888.
# Generated from the normative table in docs/plan/05-layers.md section 4;
# CompositeTest pins Composite.blend against these values.
# Convention, so a row can be checked by hand: the source is scaled by the
# opacity column first (premultiplied, so colour and alpha together), then
# combined per docs/plan/05-layers.md section 4 --
#   Co = s.rgb*(1 - d.a) + d.rgb*(1 - s.a) + both(s, d)
#   Ao = s.a + d.a*(1 - s.a)
# -- with round-to-nearest on store. both(s, d) = s.a*d.a*B(d.rgb/d.a,
# s.rgb/s.a): the mode B is applied to the UNPREMULTIPLIED channels and
# weighted by the joint coverage. Section 4's table writes that out already
# simplified into premultiplied terms (e.g. DARKEN's min(s.rgb*d.a,
# d.rgb*s.a)), which is the same arithmetic, so every row here also equals
# the W3C result. Applying the mode straight to the stored premultiplied
# bytes is a THIRD thing and gives different values -- do not hand-verify
# that way.
FF0000FF FFFF0000 1.0  FF000000  # opaque red over opaque blue
FF0000FF FFFF0000 0.5  FF000080  # the same at half layer opacity
80800000 80008000 1.0  C0404000  # half-covered red under half-covered green
00000000 FFFF8040 1.0  FFFF8040  # over a transparent destination
FF808080 00000000 1.0  FF808080  # a fully transparent source
FF404040 FFC0C0C0 1.0  FF303030  # the product darkens toward the darker factor
FFC0C0C0 FF404040 1.0  FF303030  # the product is the same either way round
FFFFFFFF FF000000 1.0  FF000000  # black over white
FF000000 FFFFFFFF 1.0  FF000000  # white over black
40200010 C0603010 1.0  D05C2411  # two partly covered pixels
FF3366AA 80402010 0.75 FF294972  # an odd pixel at three quarters opacity
FF3366AA 80402010 0.0  FF3366AA  # zero opacity leaves the destination untouched
