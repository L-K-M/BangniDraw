## 1. Bugs

### 1.1 Pigment wash and the Water tool share one rail glyph — verified. [PR]

`ToolRail.iconFor` maps `BrushToolGlyph.PIGMENT_WASH` to
`Icons.Filled.WaterDrop` (ToolRail.kt:856) — the identical `ImageVector` the
Water tool slot uses (ToolRail.kt:544 and :630). In the FULL rail both are
visible at once, and in the brush-settings chip row the pigment wash carries
the water droplet. The file's own comment states the rule this breaks:
"identical glyphs in one rail defeat the glance-recognition the rail exists
for." AGENTS.md records that marker, eraser, spray-can and Watercolor got
repo-owned silhouettes because Material has no honest glyph for them; pigment
wash (added in the 1.1.0 brush expansion) was missed. Fix: a repo-owned
broad-wash silhouette in `ToolGlyphs`, mapped in `iconFor`.

### 1.2 `brushPresetName`'s fallback shows the raw `@string/…` token — latent. [ready]

`BrushPresetName.kt`'s `when` covers today's fifteen built-in ids and falls
through to `preset.name` for anything else. Built-ins store
`@string/preset_*` as their name (verified in `assets/brushes/*.json` and
`BrushPresets.INK_PEN`), so the first built-in that forgets to register here
displays the literal token to users. Not reachable today; the cheapest guard
is a unit test asserting every shipped preset id resolves to a string
resource (assets are already read by `BrushPresetStoreTest`).

### 1.3 Nothing else confirmed this pass.

The suspicious-looking candidates all checked out: the hidden-layer stroke
previewing until pen-up is deliberate (AGENTS.md, with a toast at pen-down);
merge-down's confirm checks blend modes only because the recorded deviation
bakes a faded lower layer's opacity into its tiles, keeping the merge
appearance-preserving; `Composite.tile` skips disk reads for absent sparse
keys; the eyedropper's per-frame read gate, prediction ownership, and
graphics-core ordering were all pinned by earlier passes.

## 4. UX & convenience

- **4.1 [PR]** Panels have no close affordance — dismissal is scrim-tap or
  Back, invisible to a first-time user. A close icon in the panel headers
  (Color, Layers, Brush settings, the RMW sheets, Fill) is ~12 lines plus one
  string. Recorded in ANALYSIS.md.
- **4.2 [PR]** The mixing dish's slider position evaporates: `Prefs` stores
  only the wells, so `DishState.t` is 0.5 after every cold start
  (ANALYSIS.md #11). Persist `t` beside the wells.
- **4.3 [PR]** Keyboard shortcuts are real and undocumented anywhere in the
  UI (ANALYSIS.md #10) — a "Keyboard shortcuts" section in Settings lists the
  table for DeX/keyboard-cover users.
- **4.4 [PR]** No actual-size (100 %) zoom: reset-to-fit exists, and the
  other anchor for pixel work is scale = 1. Long-press the reset pill to jump
  to 100 % at the current view center — pure `ViewTransform` math
  (ANALYSIS.md, ds.md §3.5).
- **4.5 [PR]** Custom paper colour at creation (ANALYSIS.md #8, the last
  untouched shovel-ready original): a "+" paper swatch in the New Canvas
  dialog opening a compact HSV picker.
- **4.6 [ready]** A stroke refused because the document is busy is silent
  (ANALYSIS.md #9). The `strokeLayerNotice` toast path exists; one more
  reason string closes it, with a throttle so a busy fill cannot spam.
- **4.7 [idea]** Switching to a tool hidden in the GROUPED rail's More menu
  (blur, eyedropper) leaves the rail showing a highlighted "⋯" — a young user
  gets no confirmation of *which* tool answered. A transient one-second
  tool-name chip under the top strip (the history readout's exact pattern)
  closes the loop for every tool change.
- **4.8 [idea]** Focus mode's exit is a 6 dp edge handle; a child who opens
  it by accident may not find it. The first-run hint never mentions it.
  Either a one-time focus hint or a slightly bolder handle.

## 5. Missing features (re-prioritized for the actual user)

From the post-v1 backlog (`12-roadmap.md` §5), by delight-per-effort for a
14-year-old:

1. **Symmetry / mandala** — size S, every engine seam exists (`DabGenerator`
   emits N mirrored dabs, one journal entry, Compose guide overlay). Kids
   fill sketchbooks with mandalas; this changes *what* they draw. ANALYSIS.md
   ranks it first too. **[idea → proposal]**
2. **Image import as a paint layer** — tracing references proved the import
   seam; paint-layer import is the natural next step. **[idea → proposal]**
3. **Gradient fill** — `FillTool` variant, S. Fun and cheap. **[idea]**
4. **Time-lapse** — the kid-safest social feature there is, and the undo
   journal already holds every tile delta (session playback is the cheap
   precursor, recorded in ANALYSIS.md). **[idea, M]**
5. **Brush "save as new preset"** — recorded in ANALYSIS.md; the store
   already supports arbitrary ids. **[ready, M]**
6. **Shape assist (hold-to-straighten)** — `Stabilizer` constraint stage; the
   single most requested school-art feature after symmetry. **[idea, M]**
