# DIFFERENCE — dst src opacity expected, premultiplied ARGB8888.
# Generated from the normative table in docs/plan/05-layers.md section 4;
# CompositeTest pins Composite.blend against these values.
# Convention, so a row can be checked by hand: the source is scaled by the
# opacity column first (premultiplied, so colour and alpha together), then
# combined per docs/plan/05-layers.md section 4 --
#   Co = s.rgb*(1 - d.a) + d.rgb*(1 - s.a) + both(s, d)
#   Ao = s.a + d.a*(1 - s.a)
#   both(s, d) = s.a*d.a*B(d.rgb/d.a, s.rgb/s.a)
# -- with round-to-nearest on store, ties away from zero (NORMAL.txt's last
# row is the one that discriminates that from half-even).
#
# When s.a = 0 -- the fully-transparent-source row and the zero-opacity row --
# both() is 0 by definition, not 0/0: the unpremultiplied source is undefined
# there and must not be computed. Those rows are the destination unchanged.
# That is exactly the hazard they pin: an implementation that divides without
# guarding s.a = 0 propagates NaN instead of passing the destination through.
#
# In both(), the mode B is applied to the UNPREMULTIPLIED channels and
# weighted by the joint coverage. Section 4's table writes that out already
# simplified into premultiplied terms (e.g. DARKEN's min(s.rgb*d.a,
# d.rgb*s.a)), which is the same arithmetic, so every row here also equals
# the W3C result. Applying the mode straight to the stored premultiplied
# bytes is a THIRD thing and gives different values -- do not hand-verify
# that way.
FF0000FF FFFF0000 1.0  FFFF00FF  # opaque red over opaque blue
FF0000FF FFFF0000 0.5  FF8000FF  # the same at half layer opacity
80800000 80008000 1.0  C0808000  # half-covered red under half-covered green
00000000 FFFF8040 1.0  FFFF8040  # over a transparent destination
FF808080 00000000 1.0  FF808080  # a fully transparent source
FF404040 FFC0C0C0 1.0  FF808080  # the absolute difference of two mid greys
FFC0C0C0 FF404040 1.0  FF808080  # the absolute difference is symmetric
FFFFFFFF FF000000 1.0  FFFFFFFF  # black over white
FF000000 FFFFFFFF 1.0  FFFFFFFF  # white over black
40200010 C0603010 1.0  D0503018  # two partly covered pixels
FF3366AA 80402010 0.75 FF3D4E9E  # an odd pixel at three quarters opacity
FF3366AA 80402010 0.0  FF3366AA  # zero opacity leaves the destination untouched
